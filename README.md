I build software for sports organizations – most of my days are spent on a large Laravel application with a long history, which taught me a lot about migrations, refactoring and keeping legacy code alive. In my spare time I run my own small ecosystem of tools under the **Zhylon** brand, preferably self-hosted.

⚡ **Fun fact:** Before I became a developer, I was a cook. 👨‍🍳


### 🔭 What I'm working on

-   **[Sitealarm](https://sitealarm.app)** – uptime & website monitoring
-   **[Zhylon](https://zhylon.net)** – my umbrella for tools, IDs and side projects · [contribute on GitHub](https://github.com/zhylon/)
-   **[CodAPI](https://codapi.de)** – push and deploy a new project in seconds
-   **[Wortzalat](https://wortzalat.de)** – a Laravel side project
